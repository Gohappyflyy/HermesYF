# 授权公网资产漏洞扫描

这是供 Agent 调用 `terminal`、`read_file`、`write_file` 与 `search_files` 的操作指导，不是扫描执行器。公开可访问不等于允许扫描；不进行全网无授权探测、凭据收集或资产范围自动扩张。

## 授权资产清单

使用项目一次性批准的清单：域名、IP/CIDR、端口、URL 路径、排除项、资产所有者、时间窗口、最大并发、每目标与全局请求速率、允许测试类型、停止联系人。按批准强度自动推进；发现信息不足时仅补问缺失项，不反复要求同一授权。

确认共享主机、CDN、托管云和第三方服务的边界：域名授权不是对 CDN IP 或整段云网段的授权。新子域、证书关联域和重定向地址只有匹配清单才加入。DNS 变化和重定向须在执行时重验；公网目标解析到内网/本机地址时停止并核对，不向管理接口发请求。

## 服务识别

1. 用仓库工具发现器检查实际安装与版本。curl/OpenSSL 做 HTTP/TLS 观测；Nmap 做已批准端口和服务识别；ProjectDiscovery httpx 做 HTTP 服务分类。名称相同的软件不能视作正确工具。
2. 优先选定批准端口，结果记录协议、服务、状态和来源；不得从“公网扫描”自动升级成所有 IP 的全端口扫描。
3. HTTP 记录 URL、状态码、标题、响应头、TLS 信息和技术栈线索。观察到版本号只能产生候选，不单凭 banner 确认 CVE。
4. 按真实服务筛选后续检查，避免对无关协议使用大量模板。凭据、Cookie、完整响应体不写入普通报告或公开仓库。

## 模板审核

Nuclei/其他模板引擎：固定引擎版本、模板版本或提交、允许的模板 ID/目录、模板哈希；先检查请求及潜在副作用，再执行批准列表。severity 标签不是操作风险等级，critical 不一定破坏，info 也不一定无副作用。

独立标记请求数、认证要求、状态改变、外带目的地址、文件读写、模糊测试及 DoS 风险。code/headless/javascript 模板会执行额外逻辑，不能只凭标签放行。默认不运行未审核代码、破坏性测试或未批准外带请求。扫描器更新后重新核对参数与模板，不盲用旧版本命令。

端口识别与指纹完成后，模板扫描、爬虫、有限目录探测、漏洞验证按各自批准策略分批执行。不要把流程脚本拼接成无限递归扫描器。禁止因工具返回建议而自动扩大范围。

## 停止条件

按目标与全局两层限速、并发、请求总量、运行时限和重试次数。持续 429/503、超时或错误率异常、延迟恶化、WAF 阻断、资产负责人请求停止时暂停对应目标，保留进度与失败信息；不用换 IP、换身份或绕过防护继续扫描。恢复须按批准策略确认状态。

工具异常/缺失、授权窗口到期、目的地址变更或权限不足应标记阻塞，不以“无漏洞”结案。建立可停止的子进程及超时，不能把 `Ctrl+C` 作为唯一取消机制。

## 误报复核

扫描命中先标记“候选”：保存模板 ID、实际请求摘要、匹配器和响应证据。范围内按批准的验证方法复测，排除统一错误页、WAF 回显、缓存、版本伪装、重定向及通配符响应。必要时使用独立工具或人工检查交叉验证。

确认到证明漏洞所需的最小证据即停止，不下载真实数据库、用户资料、密钥或超出授权的数据；遇到敏感数据只保留脱敏最小证明并通知负责人。不得把漏洞存在推断成已成功利用，也不把未测试项目列为安全。

## 证据报告

输出机器可读 JSON 与简短人类报告：资产标识、批准策略摘要、工具/模板版本、时间、操作类型、脱敏证据、命中/复核状态、影响、修复建议、覆盖率与阻塞。相同资产/端口/漏洞去重，但保留不同证据来源。记录命令参数和制品 SHA-256，日志与报告分权限保存。

不要提交项目真实目标、凭据或未经披露的漏洞到 HermesYF 公共仓库。

## 验收门槛

靶场验收须覆盖已知阳性、阴性、误报、范围外重定向、CDN/DNS 变化、429/503 退避、取消、超时、敏感输出脱敏及 JSON 报告。当前仓库只有规划与发现器；文档存在或结构检查通过不等于扫描引擎/靶场验收已完成。
